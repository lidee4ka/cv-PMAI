## Как залить файлы

Проще всего — **GitHub Desktop** (https://desktop.github.com):

1. File → Add local repository → эта папка (`cv-PMAI-для-github`).
2. Publish repository: owner `lidee4ka`, name `cv-PMAI`, Public.
3. Если репозиторий уже создан на github.com/new — отметьте, что публикуете в существующий.

В браузере GitHub папки (`assets/`, `sites/`, `cases/`) часто не принимаются drag-and-drop. Не заливайте zip целиком: распакуйте и отправьте **файлы внутри**.

Если установлен GitHub CLI, в этой папке можно запустить `опубликовать.ps1` (Windows) или `опубликовать.sh` (Mac/Linux).

## Включить Pages

1. Репозиторий **Settings → Pages**
2. **Build and deployment → Source:** Deploy from a branch
3. Branch: **main**, folder: **/ (root)**
4. Save

Через одну-две минуты: **https://lidee4ka.github.io/cv-PMAI/**

Язык: русский — https://lidee4ka.github.io/cv-PMAI/ , английский — https://lidee4ka.github.io/cv-PMAI/en/ . В шапке переключатель **RU | EN**. Кнопки печати нет.

Главная — продуктовое CV. Дизайнерская страница рядом: `/cv-PMAI/designer.html` (основной дизайнерский адрес по-прежнему `/cv-reu/`).

Не выбирайте GitHub Actions и не включайте Jekyll. В папке есть пустой файл `.nojekyll`.
