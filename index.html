Тестовое · Пиксель Плюс

CJM, блокеры и ТЗ для AI Пиксель Тулс

Одно улучшение до Create: цепочка «промпты → автоконкуренты»

CJM · JTBD · RICE · Cursor сент 2026 ~0,5 рабочих дня
Проблема

На экране подобранных промптов новый пользователь не видит, что список запросов задаёт автоподбор конкурентов и основу аудита. Первая польза приходит «кривой» — цифры считаются вокруг чужого поля

Решение

За 2 дня собрала CJM пути до первой пользы, карту блокеров с приоритетами RICE, выбрала одно улучшение и оформила ТЗ плюс кликабельный прототип as-is / to-be на токенах UI Kit Пиксель Плюс

Результат

Готовый отчёт для бэклога: фокус — объяснить цепочку «промпты → автоконкуренты / аналитика» до «Создать проект» (RICE 12.2). Прототип с переключателем Сейчас / После

Вайбкодинг · BEANABOX

Оптимизация UX работы Закупщика с каталогом в Mini-app

Cursor · HTML/CSS/JS · GitHub Pages BEANABOX · сент 2026 · 8 итераций за 2 дня
Проблема

В каталоге приложения закупщик испытывал сложность с самостоятельным поиском зерна под свои задачи и был вынужден просить помощи менеджера для оформления заказа. Цель — поднять долю самостоятельных заказов с 10–20% до 30–40%

Решение

Сформулировала JTBD и гипотезу о новой структуре каталога, затем за ~15 часов активной работы собрала кликабельный прототип в Cursor — 8 итераций: рубрики слева, фильтры-чипы, sticky-панель, плотная карточка с корзиной. Цель — проверить UX самой, не дожидаясь внешней разработки

Результат

Прототип готов к проверке с 5–7 закупщиками. Критерий успеха: 5 из 7 собирают типовой заказ без менеджера. В разработку уйдёт согласованный сценарий и ТЗ — не сырая гипотеза

Логика и прототип модуля «Лот в пути»

Сокращён цикл согласования UX с ~2 недель до 2 дней

Cursor · HTML/CSS/JS · GitHub Pages ~2 рабочих дня
Проблема

Команда не утвердила макеты нового логистического флоу — иерархия карты, ETA и корзины вызывала споры. Отдавать сырое ТЗ в разработку означало риск переделок

Решение

За ~2 рабочих дня собрала кликабельный прототип в Cursor (HTML/CSS/JS), чтобы команда могла прокликать путь до разработки. В скоуп осознанно вошли: карта, ETA как прогноз, трекинг из корзины. Вырезала: подложку Яндекс.Карт, чужие порты, полноэкранный режим. Это прототип для проверки, не production-релиз

Результат

Стейкхолдеры прошли путь от карточки лота до трекинга на живом прототипе. Согласовала иерархию до старта разработки — в разработку ушло проверенное ТЗ, а не сырая гипотеза. Сократила цикл согласования UX с ~2 недель (макеты и встречи) до 2 дней
